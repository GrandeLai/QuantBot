# 加密现货规则候选研究

`crypto_rules` 是供 Agent 筛选假设的确定性决策来源，不是大模型，也不表示策略已获交易准入。它与 AI 使用同一目标权重契约、Decimal 风控、次根开盘撮合、止损和账本。原 `demo` 的 20 根正动量每日目标调仓保持不变。

## 固定信号

在每根完整 K 线收盘后计算；突破通道不包含当前信号 K 线。参数以 K 线根数为单位，日线的一根代表一天。EMA 从提供历史的第一根收盘价初始化，RSI 使用既有 Wilder 平滑实现。至少需要 35 根历史，较长 ATR 窗口另计。历史长度改变可能改变 EMA 初值影响，因此比较必须冻结相同输入。

| `strategy.crypto_rule` | 入场 | 退出 |
| --- | --- | --- |
| `momentum_hold` | 20 根收益 > 0 | 20 根收益 ≤ 0 |
| `trend_fast` | EMA5 > EMA20 且 5 根收益 > 0 | 收盘价 < EMA20 |
| `breakout` | 收盘价 > 前 20 根最高价且 EMA10 > EMA30 | 收盘价 < 前 10 根最低价或 EMA10 |
| `pullback` | EMA10 > EMA30、RSI14 < 45 且收盘价 > EMA30 | RSI14 > 60 或 EMA10 < EMA30 |
| `trend_filtered` | 最近两根都满足收盘价 > EMA20×1.005、EMA5 > EMA20×1.003、5 根收益 > 0.5%，且当前 10 根趋势效率 ≥ 0.30 | 收盘价 < EMA20 |
| `strength_rotation` | 从满足上述过滤、20 根收益为正且不在冷却期的 BTC/ETH 中选较强者 | 持仓跌破 EMA20、20 根收益非正，或符合条件的另一币领先达到预设差距 |

退出优先于入场。空仓满足入场条件时，提出 `risk.max_weight` 的目标，最终数量仍由现金、单笔风险、组合风险及交易精度限制；已有持仓保持现有数量，不每天补回目标比例。单标的或组合超限仍会缩减，保护止损独立生效。规则输出的置信度 1.0 仅表示分支确定，不是盈利概率。价格下跌后不补仓也可能错过反弹，不能预设减少换手必然改善收益。

新增 EMA5/10/20/30、5 根动量、RSI14、前 20 根最高价、前 10 根最低价及其定义同时提供给加密 AI 快照。历史已冻结的 Codex 结果不因增加特征自动变好；需创建新版本并取得新的模型调用授权后验证。

`trend_filtered` 和 `strength_rotation` 必须显式启用下面的固定止盈止损。10 根趋势效率为净位移绝对值除以 10 次价格变化绝对值之和，完全横盘时为 0。两根确认只读取完整历史，未来数据不参与计算。轮动仅接受同时提供的 BTC/USDT 与 ETH/USDT；按 20 根收益排序，最多选择一个目标标的。已有持仓仍有效时不要求重新通过更严格的入场过滤；新候选领先至少 `crypto_rotation_margin` 才切换，差距不足则继续持有。两币都弱时留现金。

## 冷却和确定性止盈止损

使用 [轮动配置示例](../config/crypto-rotation.example.toml) 可启用：

```toml
[strategy]
crypto_rule = "strength_rotation"
crypto_cooldown_bars = 3
crypto_rotation_margin = 0.01

[risk]
crypto_stop_loss_pct = 0.03
crypto_take_profit_pct = 0.06
```

固定保护默认关闭以复现既有候选，止盈与止损必须同时启用或关闭。启用后，买入成交的开盘参考价为锚：保护止损取原 ATR 止损和开盘价 × 97% 中较高者，止盈价为开盘价 × 106%。数量仍按原 ATR 风险距离保守计算，配置的单笔风险和仓位上限不提高。已有仓位增加时止损不降低、止盈目标不抬高；部分卖出后剩余数量继续受保护，全部离场才删除保护价。参数是触发价幅度，净损益另扣双边费用；跳空可能越过止损线。

执行器先处理已知的开盘事件：向下跳过止损按开盘成交，向上跳过止盈保守地按止盈价成交；开盘以后同根高低价触及两条线且路径未知时，止损优先。新买单开盘已在计划止损或更低时取消；零成交量不能成交。保护逻辑先于新策略决策运行，模型失败也不会取消已设保护。

每次完全离场记录该 K 线的收盘时间。直到当前收盘距离该时间达到 `crypto_cooldown_bars` 个完整周期才允许重入：3 根日线就是等待 3 天；参数 0 关闭冷却。此限制既用于规则选择，也由独立风险规划强制执行，模型提出买入同样不能绕过。保护价和退出时间持久化，重启不清空；部分卖出不重置冷却。

上述功能使用统一 `backtest` / `runtime` 执行器；旧 `crypto ai` 直接执行路径遇到这些配置会明确拒绝，避免静默忽略止盈或冷却。

## 使用

```sh
.venv/bin/quantbot backtest --market crypto --provider crypto_rules \
  --config config/crypto-rules.example.toml --data data/crypto-development.csv \
  --last-bars 41 --output runs/crypto-rules-development
```

示例配置选择 `trend_fast`，本金 1000 USDT，单边成本 15 bps，单标的最大 20%，单笔风险 0.5%。原四种候选之间切换仅修改 `strategy.crypto_rule`。支持现有的 15m、1h、1d 行情；本轮研究使用 UTC 日线。该新来源目前由 CLI / runtime 使用，网页 AI 配置选择器未增加它。

轮动回测使用 `--provider crypto_rules --config config/crypto-rotation.example.toml`，并提供同时包含 BTC/ETH 的开发段 CSV。原示例和新示例的保护配置不同，应在登记候选时冻结完整配置。

需要冻结运行风控时，使用 `runtime create --market crypto --provider crypto_rules --config ... --source csv --data ... --bar 1d --max-daily-loss 0.02 --max-drawdown 0.05`，再按研究协议评估。新任务默认暂停，不需要启用 worker。

撮合仍使用模拟精度和估计费用；未对接 OKX 交易账户。末尾存量按市价估值，未虚构最后一根清仓。`quantity_step_no_change` 表示目标取整后无需交易，区别于 `cash_or_risk_budget_rejected`，不改变实际订单。

## 筛选边界

先固定有限候选、开发区间、成本和淘汰规则，再比较全部结果，包括失败和零成交。检查独立窗口与连续开发期表现、双倍成本、成交及活跃天数，并从回放日志独立对账。开发段反复优化的收益不能标为样本外；独立留出不得传给这一筛选流程。

基础 `passed` 仅表示执行完整，不是盈利准入。研究候选盈利后仍需按 [加密分级准出](CRYPTO-ADMISSION.md) 完成独立验证及其他证据；确定性规则盈利也不能替代 AI 决策验证。

## 2026-10-22 开发段试验

固定 BTC/ETH 日线、三个 41 根窗口（2026-03-01 至 07-01，UTC 收盘时点）、每窗 1000 USDT、单边 15 bps。三窗平均净收益：原动量 -1.1094%，持仓型动量 -0.3320%，快速趋势 -0.2504%，突破 -0.2597%；回撤规则零成交。快速趋势仅第二窗 +0.1884%，相同开发期连续运行仍为 -0.5413%。没有候选通过预登记的正收益与窗口稳定性筛选，未进入独立留出或交易阶段。

包含双倍成本及连续持仓检查的 40 次正式回放均完整，2460 个账户快照独立对账无差异；相关测试 120 项通过，实际模型调用 0 次。一次汇总字段错误导致首批处理中断，该基准窗口的回放和错误证据另行保留，修正汇总后原方案重跑。减少换手的候选实际暴露也更低，因此不能把亏损收窄全部解释为信号质量提高。这些开发区间已被研究过，不是样本外验证。

## 2026-10-22 第二轮：冷却、趋势过滤与 BTC/ETH 轮动

沿用同一开发数据和成本，运行前登记 7 个候选（含 2 个原有对照），新增候选统一采用原 ATR 与 3% 固定止损中较紧者、6% 止盈。三个独立窗口与连续开发期均检查，另以单边 30 bps 重跑成本压力测试；没有事后增加参数组合。

| 连续开发期，1000 USDT 起始 | 单边 15 bps 净收益 | 单边 30 bps 净收益 | 15 bps 成交数 |
| --- | ---: | ---: | ---: |
| 原动量对照 | -1.7993% | -3.5312% | 77 |
| 原快速趋势对照 | -0.5413% | -0.6355% | 20 |
| 快速趋势＋固定止盈止损 | -1.0179% | -1.3393% | 50 |
| 上项＋3 根冷却 | -0.1756% | -0.3252% | 28 |
| 上项＋两根确认及趋势效率过滤 | -0.1319% | -0.3145% | 18 |
| BTC/ETH 轮动，领先 1 个百分点、冷却 3 根 | -0.5000% | -0.6308% | 16 |
| BTC/ETH 轮动，领先 2 个百分点、冷却 5 根 | -0.6994% | -0.8013% | 14 |

没有候选通过扣费盈利与窗口稳定性筛选。新增 5 个候选的前两个独立窗口均亏损，第三窗均零成交。固定止盈止损单独使用反而增加了退出后的重入；冷却和过滤降低了换手及亏损，但过滤版连续期平均实际仓位仅 1.29%，较低暴露也是回撤减少的原因。两种轮动配置均弱于过滤版，不能据此认定存在轮动收益优势。

本轮 147 项相关测试通过；56 次回放完整，3444 个账户快照独立对账无差异，262 笔带固定保护的买入及冷却、轮动持仓审计无违规。实际日线样本没有同根双触发，该边界由确定性测试覆盖。准出政策源码与上一轮冻结版本完全相同；独立留出未启用，实际模型调用 0 次，所有研究任务保持暂停，未进入 OKX 模拟盘或实盘。这仍是开发段规则研究，不是样本外盈利或 AI 策略验证。
