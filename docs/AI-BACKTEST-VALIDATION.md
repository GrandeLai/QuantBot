## 证据边界

验证覆盖本地规则回测及受控模型失败场景，没有调用真实大模型、交易所或券商执行接口。收益来自合成行情，不作为策略有效性证据。真实模型回测仍需配置兼容服务；本地 Agent 可编排命令和读取报告，Codex/Claude CLI 尚未接成决策供应方。回测不包含真实流动性、部分成交及完整公司行动记账。
