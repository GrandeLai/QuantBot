# 四机制执行探针

这一层回答“新增机制扣费后是否产生稳定增量”，不直接创建可交易策略。入口为 `python -m quantbot.factors.mechanism_study`，全程离线，模型调用为 0。候选使用现有目标仓位、独立风控和次根开盘撮合；所有行情、公司行动、原点、代码和试验身份在运行前冻结。

## 四项机制

| 机制 | 冻结入场规则 | 对照 | 探针期限 |
| --- | --- | --- | --- |
| 加密中期趋势 | BTC/ETH 60 日收益 > 0 且收盘 > SMA120 | 同时点 20 日正动量 | 20 根；20 日收益转非正提前退出 |
| 加密震荡回归 | SMA20/SMA60 距离 ≤ 2%、20 日效率比 ≤ 0.25、z-score ≤ -2 | 同样超跌条件，不加震荡过滤 | 10 根；z-score ≥ 0 提前退出 |
| ETF 跨资产趋势 | SPY/QQQ/IWM/IEF/GLD 的 63 日总收益 > 0、总收益指数 > SMA126 | 仅 SPY/QQQ/IWM 的相同条件 | 月末信号，20 根 |
| 行业相对强度 | 九行业 63 日总收益同时高于 0 和 SPY，选前两名 | 九行业请求等权、请求总仓位相同 | 月末信号，20 根 |

BTC/ETH 在同一原点账户中共同检验，不按结果挑选资产。行业对照仍受原有最多 5 个持仓限制，使用原有 `factor_score` 排序：它是“九行业等权请求经现有风控后的可执行对照”，不能声称实际持有九个等权仓位。后续如改变该对照，必须作为新假设登记。

原 3% 止损和 6% 止盈是触发规则，不能保证成交损失被限制在该百分比；跳空、零成交量和费用仍按原引擎处理。

每个原点只有一次入场请求，订单取消或保护退出后不重新入场。日常保持已有仓位的当前权重，原风控可以减仓；没有中途换仓或补仓。期末剩余仓位按收盘估值并额外扣估计卖出费用，不能写成已平仓成交。每个探针重置本金，因此平均原点收益不是连续策略收益，更不能复利或年化。

## 数据和公司行动

执行使用当日价格和股数；信号使用截至当前收盘可计算的特征。普通现金分红在除息日确权，支付日到账；总收益信号允许理论再投资，现金账户的实际可用资金仍遵循支付日。拆股在生效时调整份额、成本和保护价格，历史特征只调整已生效的拆股。股息税、融资、容量和日内先后次序未完整模拟。

`ResearchSnapshot` 只服务明确标注的事后重建。公告时间未知继续保留 `available_at: null`，不会修改生产快照的时间契约。原始供应方返回、事件来源、金额和单位核对结果应单独存档。缺失、不合法的 OHLCV 不前填、不删日、不改股票池；相关假设在运行前记为数据阻断，仍计入多重检验。

## 冻结与运行

准备显式 `PROTOCOL.json`，引用原研究卡片、研究目录、两市场的行情/公司行动/质量文件及哈希，保留原费用、风险、窗口和统计阈值。先记录读取区间，再运行：

```bash
python -m quantbot.factors.mechanism_study freeze \
  --protocol /absolute/PROTOCOL.json --freeze /absolute/execution-freeze.json
python -m quantbot.factors.mechanism_study run \
  --protocol /absolute/PROTOCOL.json --freeze /absolute/execution-freeze.json \
  --output /absolute/new-study-directory
```

输出目录必须不存在。冻结文件包含准确原点和源码哈希；开始和结束时检查一致性。两市场并行，每次运行保留逐步日志、独立现金流对账、全部费用档和失败原因，成功完成后向不可变研究目录追加四项结果。异常保留 `failed.json`，不能覆盖失败目录或偷偷重试模型调用。

三个开发窗口分别是 2019–2021、2022–2023、2024–2026 上半年；加密最晚完成收盘为 2026-07-01，美股最晚交易日为 2026-06-30。每个窗口前 20 根不入场、末 20 根不产生新原点，并保证完整持有期限不跨窗口。信号预热可读取更早、已登记的开发行情。

筛选要求：两档单边费用 15/30 bps；特征覆盖 ≥95%；每窗实际买入成交 ≥5、合计 ≥30；至少两窗净收益和相对对照的增量同时为正；两档费用的池化净收益/增量均为正，20 时点日历块 bootstrap 的 95% 下界也均为正。固定 4,999 次重采样、随机种子 1729。所有已知历史失败和新假设共同参与 Holm 校正，该轮家族 134 项；不可用或硬门槛失败记 p=1，不缩小检验家族。

历史时点可得性未认证、未完成对账或账户触发熔断，均不能入池。统计达标也只是因子研究候选，仍需另行冻结连续策略并用未参与筛选的数据验证；研究目录永远不能直接批准模拟盘或实盘。
