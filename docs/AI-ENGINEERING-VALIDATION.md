# 研究工程完善与回归记录

日期：2026-10-18。当前验收以一次性离线回测为主，指定券商与交易所渠道继续暂缓。

## 已核验的改动

- 历史账户的持仓、止损和订单使用独立快照，后续交易不再改变先前记录。
- 回测、滚动评估和研究逐步落盘输入、决策与成交；失败下载和中断检查保留已有证据，撤回旧准入，不重试未确认调用。
- 已生成证据的输入校验失败也提供下载地址，保留 ValueError/HTTP 400 契约；运行异常仍返回 HTTP 500。
- 中文日志在 UTF-8 字符中途截断时，仍能读回之前的完整记录；日志中间损坏则报错。
- 失败研究的看板汇总已留存的调用尝试和已报告用量，明确区分缺失用量和结果未确认。
- 网页和 CLI 使用后端标准 CSV 解析，支持 BOM 和带引号字段。滚动评估对照日志标明实际规则身份。
- 新增只读现金流核验；从成交重算现金、持仓、平均成本、损益、费用、权益和回撤，并定位不一致时点。
- 前端构建同步 Python 包内网页，避免源码工作台与安装包展示不同版本；源码包包含前端同步工具和文档中的可运行验收脚本。
- 末轮撮合复查修复零成交量仍产生普通/止损成交的问题：美股和加密的买入、卖出、保护止损共 6 个样例在修复前全部复现；修复后取消该次成交，保留现金、持仓、成本和止损。

## 测试范围与结果

广泛 Python 回归在禁止全部网络连接时：**3329 项通过、3 项失败，471 个子测试通过**。3 项失败均因禁止网络的验收约束阻止了测试自行启动的本机 HTTP 服务。确认这些服务只返回固定测试响应后，单独允许这三项的本机连接、继续禁止外网，**3 项全部通过**。因此该集合共 3332 项已分别验证，不能将首轮结果描述为一次全绿运行。

更早的第一次尝试在模型库导入时读取远程价格表，被离线约束阻断；后续使用 `LITELLM_LOCAL_MODEL_COST_MAP=True`，读取随依赖提供的本地表。没有调用实际模型。最终广泛回归日志有 1508 条警告，主要来自现有依赖和历史模块，不表示告警已清零。

广泛回归之后，新增账目核验相关 **27 项通过**，覆盖手算分批买卖、部分卖出、全部平仓、重复成交/超卖拒绝、历史记录改动、旧日志无法核验、股票/加密实际回放和只读 CLI。联合回归包含全部 `test_ai_*.py`、期权覆盖、SEC 事件/归档、统一网页接口及价格行为时点检查，**193 项通过，945 条警告，耗时 159.35 秒**。该次包含账目核验和校验失败下载改动，发生于末轮零成交量修复之前。各批次范围有重叠，不累计计算；广泛集合未在最终改动后整套重跑。

前端 **39 项测试通过**，生产构建成功。网页实际导入带 BOM、全字段引号的双标的合成 CSV，策略及对照的完整行情快照、决策、订单、权益和收益与直接回测一致；控制台错误为 0。

末轮零成交量修复后，运行账户/回测/账目核验/逐步日志/历史版本/统一接口的 **81 项通过，513 条警告，耗时 65.28 秒**，包含 6 个修复前失败的直接复现。该轮修改的源码指纹为 `8c438a2f3ee730759490799285524cd003503bc6ce5354288fabd1f8644a48fe`，两个修改文件的静态检查通过。日志保存在 `runs/engineering-validation-20261018/zero-volume-reproduction.log` 与 `zero-volume-regression.log`。
