# 双市场状态归因与条件入场因子

`quantbot.factors.conditional_study` 先重建 BTC 过滤突破和美股 ETF 两日确认轮动的真实持仓周期，再筛选对原策略有扣费后增量的入场因子。该入口读取冻结的离线行情与已完成回放日志，不请求策略模型，不访问交易账户，不授予准出。

## 运行与证据

研究协议需先保存为 `PROTOCOL.json`，同目录 `protocol-freeze.json` 记录其绝对路径与 SHA-256。协议登记两市场的 CSV、股票公司行动、原基准报告与八次日志、三个开发窗口、连续账户、旧试验记录和保留政策。解释文档也绑定哈希。执行前校验所有引用，再冻结实际研究源码；运行前后复核指纹。

在项目根目录运行；路径替换为已有的冻结协议，输出必须不存在：

```sh
PYTHONPATH=src .venv/bin/python -m quantbot.factors.conditional_study freeze \
  --protocol /absolute/path/PROTOCOL.json --output /absolute/path/new-study
PYTHONPATH=src .venv/bin/python -m quantbot.factors.conditional_study run \
  --study /absolute/path/new-study
```

这是本轮固定设计的研究入口，不是任意参数优化器。协议必须满足源码内登记的状态定义、四因子、成本、窗口和检验预算；不能修改已冻结协议重试新假设。复现旧研究应从该次 `frozen-source.tar.gz` 恢复源码到隔离目录，用原协议登记一个新输出目录，保留原始运行。已有目录或已执行的研究不会被覆盖；失败保留日志与 `failed.json`。

两个市场的归因可并行；只有归因全部完成并落盘后才开始因子筛选。主要产物：

- `execution-freeze.json`：源码与协议指纹、编译后的因子和检验定义。
- 每市场 `entry-context.csv`、八份 `*__entries.json` 与 `state-diagnosis.json`：事前特征、闭合/未闭合周期、逐状态/标的贡献、独立对账。
- `STATE-DIAGNOSIS.md`、`FACTOR-RESULTS.md`、`result.json`：可读归因、全部八项成败及原因、研究池和下一步状态。
- `diagnosis-completed.json`、`completed.json`：归因完成时间与最终结果哈希；不是策略准出凭证。

## 时间与账户口径

趋势按 BTC 或 SPY 基准的收盘、EMA50、EMA200 分为上升、下降、混合；20 根收益波动高于此前 126 根波动中位数为高波动，否则普通波动。EMA 完整预热，波动比较基准延后一根，合计六种事前状态；预热不足保留 unavailable。

买入通过原决策的订单 ID 精确取得 `signal_at`，再对齐特征。不能用成交日期减一天代替，尤其加密 UTC 收盘与次期开盘可能同一时刻，美股存在周末和提前收盘。持仓中的风险减仓不拆成新周期。美股分红按原持仓权益计入，支付到账不再次形成利润。

各成本档独立重建原规则回放路径并从成交、现金流重做对账。日权益变化按上一已完成收盘状态分类；入场周期按原信号状态分类，两者不能混用。`close_flat_days` 只表示收盘无仓，不能声称盘中全程现金；风险停机起点、停机后估值日和收盘空仓日另列。

三个开发窗口的闭合持仓周期用于筛选，连续账户只用于归因，避免重复计数。未平仓周期单列，不能视为零收益或强制虚构平仓。当前研究历史已经用于开发，不属于独立样本外证据。

## 固定因子与筛选

| 因子 | 入场保留条件 |
| --- | --- |
| 成交量确认 | 当日量 / 此前 20 根平均量 ≥ 1 |
| 收盘位置 | (收盘−最低) / (最高−最低) ≥ 0.75 |
| 波动收缩 | 5 根收益标准差 / 20 根收益标准差 ≤ 1 |
| 趋势持续性 | 最近 10 根收盘高于同期 EMA20 的比例 ≥ 0.8 |

缺值和零分母不保留入场，并报告覆盖率。每个因子既检验保留周期的净贡献，也检验 `delta=(keep−1)×原周期净损益/初始资金`。过滤一笔盈利会产生负增量，不能只看保留交易的单笔平均值改善。

这属于固定旧成交路径的事件消融，未重算过滤后的现金、冷却和新机会，**不是新策略账户收益**。三个独立窗口的贡献合计也不是连续复利收益。

基础与压力单边成本分别为 15/30 bps。每档要求每窗有效覆盖率至少 95%、保留至少 5 个周期，合计保留至少 30、过滤至少 10；至少两窗保留净贡献与增量同时为正，三窗平均两者为正。随后在真实 session 网格上进行 20 根循环区块重采样，4,999 次、种子 1729；两个指标在两档成本的 95% 区间下界都必须大于零。

非事件日保留时间间隔，不充当交易分母。保留净贡献按保留事件数、增量按原事件数计算。原始联合 p 取双指标双成本的最大值；任一必要门槛失败，家族使用 `p_value=1`，诊断原始值保存在 `raw_p_value`。本轮八项联合 116 项既有记录，以 Holm、0.05 校正：102 个核验过的旧因子原始 p，加 3 个旧确认登记和 11 个旧策略暴露的 p=1 占位。占位不是可比的已测 p，也不能消除历史选择偏差。

只有全部通过者才按固定因子顺序进入每市场最多两个候选的研究池。空池不构建新策略；有入池者也需另行冻结单因子策略并完成账户回放，当前筛选入口不自动构建或运行策略。新策略仍需全部原开发检查和增量检查，正式准出政策保持独立。

## 本轮实际结果

2026-10-22 UTC 完成本轮；读取 16 次既有基准回放，独立复核 18,488 个账户快照。筛选每档成本使用 BTC 77 个、美股 ETF 140 个闭合周期，八因子特征覆盖均为 100%。四个新模块的 47 项测试及 44 项相关回归通过，Ruff 通过。

**八项因子均未通过，新策略回放为 0。** BTC 四种过滤的净增量都为负；ETF 趋势持续性两档成本均有正点估计，但置信区间跨零。不能据此将该因子写成已验证的策略优势。

本轮基准收益仍是原来的开发结果：BTC 连续账户累计净收益 +3.3974% / +1.9095%；ETF 两日确认轮动累计净清算估计 +4.3582% / −0.8893%（15/30 bps，均非年化）。本轮没有新增账户回测，也没有提高原策略收益。
