# 加密因子研究：扩展验证窗口与研究家族

当前交付 P0～P2：可信指标、12 个固定因子、历史面板、1/5/10 日标签和时间序列开发验证。
输出是待进一步构建策略的因子证据，不是盈利策略、实际收益或交易准出。

## 本地 Agent 的运行方式

只需要基础 Python 依赖 numpy/pandas，不加载模型配置、登录凭据、券商账户或 RD-Agent 研究模型。
先准备仅含开发区间的 CSV，再登记，最后按返回的 study 路径运行：

```sh
.venv/bin/quantbot factor-study register \
  --data data/development-daily.csv --root runs/crypto-factor-family \
  --development-end 2026-07-01T00:00:00Z \
  --protected-holdout-start 2026-07-03T00:00:00Z \
  --provenance data/development-provenance.json \
  --validation-days 730

.venv/bin/quantbot factor-study run --study runs/crypto-factor-family/<登记返回的研究ID>
```

`--validation-days` 冻结每个验证窗口长度，默认 180，允许扩大但不能缩短到 180 以下。
窗口只在登记时选择，不得看结果后修改。因子定义、成本、有效事件门槛与交易准出政策保持不变。

`--root` 在同一研究家族内复用时，自动纳入已有登记及其祖先研究，包括失败和未完成项。
从其他目录继续时，传入 `--prior-study <旧研究目录>`；可重复指定。程序核对旧登记和结果哈希，
按研究/试验身份去重，把既有原始 p 值冻结进 `prior-factor-evidence.json`。
旧报告与旧目录不修改；新目录的 `ledger.jsonl` 记录本轮登记与失败。
登记冻结数据、公式、方向、窗口、成本、源码指纹和全部 72 项诊断。登记不计算收益。
运行一次后不能覆盖或自动重跑；中断保留 `started.json`，异常保留 `failure.json`。
改代码、数据或参数需要新登记，失败仍计入试验记录。账本与哈希用于本地一致性检查，
不构成防恶意篡改的认证，也不生成正式交易准出凭证。

CSV 列：`timestamp,symbol,open,high,low,close,volume,bar`。本版只接受 BTC/USDT、ETH/USDT、`bar=1d`。
`timestamp` 为 UTC 午夜的开盘时刻，`development-end` 为最后允许使用的收盘时刻。
两个币必须日期一致且连续，价格必须有限且为正、OHLC 合理、成交量不能为负。
重复、缺日、错位和超出开发边界直接拒绝；不会静默裁剪留出或补齐价格。
传入 CSV 前就应剔除留出；入口拒绝越界不能替代上游的数据隔离。
历史行情的真实发布时间、修订与可交易容量仍需另行验证，来源 JSON 只保留声明。

## 固定因子

| 名称 | 角色 | 定义摘要 |
| --- | --- | --- |
| momentum_20 / momentum_60 | 收益预测 | 20/60 日收益除以同窗日收益样本标准差 |
| breakout_20 | 收益预测 | 收盘减此前 20 根最高价，再除 ATR14 |
| close_location | 收益预测 | (2×收盘−最高−最低)/(最高−最低) |
| ema_reversal | 收益预测 | 收盘偏离 EMA20 的反向值，除 ATR14 |
| reversal_3 | 收益预测 | 3 日反向收益除 20 日日收益标准差 |
| signed_volume | 收益预测 | 涨跌方向乘当日成交量/20 日均量 |
| illiquidity_20 | 风险诊断 | 20 日平均：绝对日收益/(收盘×基础币成交量) |
| efficiency_10 | 状态诊断 | 10 日净变化绝对值/逐日绝对变化之和 |
| volatility_ratio | 状态诊断 | 5 日日收益标准差/20 日日收益标准差 |
| relative_momentum_20 | 收益预测 | 本币相对另一币的价格比，20 日对数变化；两个信号相互依赖 |
| eth_residual_20 | 收益预测，仅 ETH | 用当前 20 根之前的 60 根拟合 BTC 回归，再累加当前 20 根 ETH 残差 |

每个定义记录版本、公式、窗口、输入、单位、经济假设、失效条件与哈希。
方向按经济假设预先固定，不根据验证结果翻转；EMA 以首个收盘为种子，ATR 为 14 根真实波幅简单平均。
预热不足、零分母、量价因子的零成交量及 BTC 不适用的残差因子均保留明确缺失原因。
未观测值不补零。面板中的因子只读取当前及过去数据，未来标签单独计算。

## 标签和成本

信号在当天收盘可用，次根开盘入场，第 h 个后续开盘退出，h 固定为 1、5、10。
净事件收益为 `退出价×(1−c)/(入场价×(1+c))−1`，单边成本 c=15 bps，压力为 30 bps。
末端缺少完整未来价格、入场或退出日零成交量时，不生成收益值。
同时输出本币减另一币的同期间毛收益差，用于相对 Rank IC 诊断；
它不包含轮动换仓的实际成本，不作为本轮入池门槛，也不能冒充轮动收益。

这是固定持有事件，未模拟止盈、止损、持仓重叠、数量精度、成交概率和账本。
次根开盘即时成交与固定成本是研究假设，不是 OKX 实测成交成本。
已有 ATR/3% 较紧止损、6% 止盈、冷却及账户风控保持在原策略执行器中；
后续因子策略必须经过同一执行器验证，不能用这里的事件均值冒充带保护策略收益。

## 筛选规则

固定 3 个末尾开发验证窗口，每窗默认 180 日，可通过 `--validation-days` 扩大。
例如 730 日对应 2190 日开发验证；前段为逐次扩展训练，仍要求总历史不少于 1095 根。
扩大窗口时要同时留下足够的预热与训练历史，不能把验证之前的所有行数等同于有效训练观测。
每窗至少 365 个有效训练观测、120 个验证观测，特征覆盖率至少 95%。
训练标签退出必须早于验证开始前 1 日，验证标签不能越过本窗边界。
分位阈值由各窗训练段计算；相关性去重仅使用第一个验证窗口之前的数据。

BTC、ETH 分别计算时间序列 Rank IC，不计算两币横截面 IC。
12×2×3 共 72 个记录：51 个可用 alpha 假设、18 个状态/风险诊断、3 个不适用项。
失败、未完成和缺样本项保留 p=1，不缩小比较数量。每轮的 51 项加上冻结的既有预测假设，
统一进行 Holm 校正；例如首轮 51 项加本轮 51 项，校正家族大小为 102。

预测因子进入开发候选池必须同时满足：

1. 三窗训练方向均为正，至少两窗验证 Rank IC 和条件净事件收益同时为正。
2. 超过训练 80% 分位的信号，在固定 h 日事件网格上每窗至少 5 次、总计至少 30 次。
3. 双倍成本下平均净事件收益仍为正。
4. 20 日区块、固定种子、4999 次 bootstrap：条件净均值及相对同日历网格无条件均值的增量，下界均大于零。
5. 同时检验净均值和增量，取两者较大的 p 值；本轮及已冻结既有预测假设统一 Holm 校正后 p≤0.05。

网格事件不重叠。分位收益与 IC 可用重叠标签，报告明确标记，不把它们当独立交易次数。
上述统计检验是开发期探索证据，区块重采样与非平稳市场仍有局限。
短持有期和较长持有期的有效样本数差异很大；5/10 日样本不足时直接标记，不降低要求。

通过者按首窗训练 Rank IC 排序，剔除训练绝对相关性>0.65 的重复信号，最多保留 6 项。
同一因子的多个持有期也去重。三种状态/风险因子只输出分位条件诊断；没有策略消融就不启用过滤。
这里的无条件事件对照用于检查因子筛选是否提供增量，不是匹配暴露的组合回测。
策略级移除因子消融、组合评分与因子到目标仓位映射仍属于 P3。

统计校正覆盖登记时已知且通过证据核验的因子研究家族；未导入的其他目录、未登记的人工搜索、
策略研究与以后新增研究均不在范围内。以后完成的旧未完成试验不会回写本轮冻结快照。
这不是覆盖无限后续搜索的顺序错误率保证，也不能把已暴露的开发区间重新命名为独立验证。

## 报告与边界

- `preregistration.json` / `freeze.json`：完整冻结条件与指纹。
- `prior-factor-evidence.json`：既有研究的身份、原始检验结果、失败/未完成状态和来源哈希。
- `factor-panel.csv` / `forward-labels.csv`：分离的历史因子与收益标签。
- `result.json`：全部诊断、分窗稳定性、分位条件收益、1/5/10 日表现、覆盖率、相关性和区块不确定性。
- `report.md`：空池或开发候选结论。
- `artifact-manifest.json`：该次运行产物校验清单。

`empty_pool` 是有效研究结论，不是工程失败。出现开发候选也必须先构建少量策略，
通过现有回测与独立对账，再按原冻结政策评估独立留出；达标前不进入 OKX 模拟盘。
本命令的 `trading_admission` 始终为 false，真实策略模型调用数为 0。

旧组件一并修正：RD-Agent 缺指标不能补达标默认值；NaN/无穷数不能通过旧因子准入；
两个横截面样本、单个 IC 观测与零方差不能产生可准入的 ICIR。
IC `available` 仅表示统计量可计算，不代表样本已具备投资意义。
RD-Agent smoke 仅验证构造对象，永不执行研究或返回伪造的收益指标。
