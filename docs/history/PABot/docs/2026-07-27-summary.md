## 一、已实现功能

### 1. 数据层

- [x] yfinance 日线下载 + parquet 本地缓存（前复权，批量多线程，限流保护：
      整组空结果比例异常时不写退市标记）
- [x] **数据快照版本化**：先在同文件系统临时目录复制并对复制品计算哈希，
      全量自校验和 fsync 后原子改名、设为只读；失败不遗留半成品，目标存在
      或 ID 越界即拒绝；快照模式禁止一切下载写入
- [x] **快照消费全量校验**：回测/实验/发布在读取前逐文件 SHA-256；旧 schema、
      清单一致但内容漂移均 fail-closed（现有两份旧快照已据此阻断）
- [x] **完整只读消费链**：行业、财报、点时成员与行情统一读取已验证快照；
      附属缓存缺失时拒绝，不自动补数；目录解析不改写调用方配置及配置哈希
- [x] **标普 500 点时成分股池**（fja05680/sp500 数据，消除选股幸存者偏差）
- [x] **Ticker 改名别名映射**（32 组：FB→META、PCLN→BKNG、FI→FISV 反转、
      NLOK→GEN 等，恢复约 4 万个候选日）+ 代码复用防护（Q/Qnity 案例）
- [x] 成交额 Top-100 流动性池（点时可计算，重构"当时的大盘股"）
- [x] GICS 行业分类缓存（行业集中度约束用）
- [x] 财报日历缓存（财报回避用，该功能已证伪默认关闭）
- [x] ^IRX 国债利率序列（闲置现金计息）
- [x] 运行缓存与研究缓存物理隔离；前者进一步按 mode/匿名账户分区
- [x] `download --force` 可重试空标记（误伤自愈通道）

- [x] **预注册单变量实验层**：同快照/同数据对象基线候选双跑、配置/源码/

- [x] **不可覆盖候选包**：精确冻结候选/回滚配置、原始实验、源码与快照

      末尾连续合格日计数；旧账本不追认，不能次日补采或覆盖不合格结果

### 5. 实盘 / 模拟盘（Alpaca）

- [x] 券商抽象接口 + Alpaca 实现（命令/config 双重确认 paper/live）+ DryRun
      演习模式
- [x] **SimBroker 本地模拟盘**（`main.py sim`）：无需任何密钥，本地持久化
      记账（现金/持仓/均价），最新行情价 ±5bp 撮合，无行情拒单——
      密钥到位前可积累联调数据；与 Paper 的账户、状态和证据分别维护
- [x] **运行模式与账户隔离**：dry-run/sim/paper/live 的状态、锁、备份、
      SQLite、行情缓存、CSV 和报告分别存放；旧未分区状态阻止交易模式启动，
      不自动按空账户迁移；演习不能清空 Paper 持仓或覆盖 checkpoint
- [x] Yahoo↔Alpaca 代码格式互转（BRK-B/BRK.B）
- [x] 每日 runner：半根 K 线剔除（时区安全）→ 离场 → 加仓 → 入场 → 底仓
- [x] **按信号日精简交易行情**：生产点时池先加载完整基准日线，再刷新
      该日成员与账户实际持仓；退出指数持仓仍参与止损检查，研究保留全历史池
- [x] **订单结算闭环**：等待终态；超时先撤单再复核；部分成交按实际入账；
      状态不明立即停止一切开仓；卖单失败保留原止损；买单失败无幽灵持仓；
      离场失败持仓当日禁止加仓；真实成交价回填状态
- [x] **跨进程订单幂等**：所有订单先落 planned 事实与稳定 client ID；
      Alpaca/SimBroker 重启先查已有订单，未知提交结果只读恢复、不重复提交
- [x] **启动恢复门禁**：进程锁后、行情/交易前只读核对账本未决订单和券商
      全部工作订单；未知、部分成交、外部订单、读取失败或成交后未完成状态
      交接一律 HOLD，`--force` 不可绕过，不自动补单/撤单/修复
- [x] 跳空保护（实时报价复核，与回测逻辑一致）
- [x] 拆股侦测（均价同比例交叉验证；不符则冻结该标的并告警）
- [x] 交易日检查 + 当日幂等性（`--force` 补跑）+ 进程文件锁
- [x] 数据熔断（基准陈旧 >4 天不交易；持仓股缺数据单独告警）
- [x] 状态文件：文件/目录 fsync + 原子写入 + schema v2 单调 checkpoint +
      订单交接同事务 + 启动回滚检测 + 每日备份 + v1/v2/v3 状态格式迁移
- [x] webhook 通知（飞书/通用自动识别）+ 心跳死人开关（healthchecks 类）
- [x] **严格三态影子对账** `reconcile`：强制刷新独立缓存；标的/方向/准确
      股数比较；券商/数据/回测失败返回 UNKNOWN，禁止本地状态 fallback；
      `--mode sim` 使用本地模拟券商，独立影子结果不替代 Paper 收盘事实
- [x] **绩效跟踪闭环** `report`（每日权益/滑点落盘；实际 vs 影子回测对比；
      滑点校准建议）
- [x] **短样本报告直接生成**：不足 5 个不同交易日时使用已有权益和成交
      生成报告；达到 5 天后再准备影子回测，保留重叠天数与失败状态说明
- [x] **SQLite 只追加复盘账本**：运行、候选决策、订单、成交、持仓、权益、
      对账七类事实；WAL/FULL、外键、幂等冲突、UPDATE/DELETE 禁止
- [x] 中文日报 `review`（数据/决策/执行/账户四层，缺记录明确为证据不足）
- [x] review/report 支持模式和账户选择，多账户不按最近目录猜测；正式
      Paper 审计按 campaign 账户读取只读账本
