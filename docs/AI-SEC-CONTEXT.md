# SEC 公告接入主 AI 回测

主美股回测和预登记研究可把 SEC 8-K/8-K/A 归档作为模型证据。价格特征、公告输入和账户事实共同送入模型；模型仍只提出目标持仓，原有独立风控与次根开盘撮合继续生效。

价格行为/离线规则不使用公告做决策，因此规则跑通只能验证数据传递与回测工程，不能验证模型理解公告的效果。真实大模型调用仍需显式 `--allow-model-calls`。

## 输入与命令

公告输入是一个独立 JSON，包含 `schema_version: 1`、`bundle`、`universe`、`policy` 四个字段：

- `bundle`：完整 SEC 归档，沿用 [事件数据契约](AI-SEC-EVENTS.md)，含原文、正文版本、采集时间与季度覆盖。
- `universe`：带有效日期的 `cik/symbol/start/end` 列表。允许部分股票没有公告映射，决策中会明确标记缺口；同一时点不能把一个代码映射到多个公司。
- `policy`：可留空对象，默认按首次取得时间、处理延迟 60 秒、回看 7 个自然日、每个股票最多 3 个事件、每篇正文前 2000 字符，包含修订申报。

```bash
quantbot backtest --provider demo --data prices.csv \
  --sec-context sec-context.json --last-bars 30 --output runs/sec-aware-backtest

quantbot runtime create --name '公告策略候选' --market stocks \
  --provider ai --source csv --data prices.csv --sec-context sec-context.json
```

第二条只登记暂停候选。随后可通过原有 `evaluate`、`walk-forward`、`study-create` / `study-run` 完成评估与研究。带公告输入的候选暂时只允许回测与研究，不能恢复为持续模拟任务。加密市场、单次交易计划和券商执行入口拒绝该输入。

完整可复制的离线例子：

```bash
.venv/bin/python docs/examples/validate_ai_sec_context.py \
  --output runs/ai-sec-context-validation-new
```

该命令生成明确标记的合成行情/原文，执行主回测与研究，禁止所有网络访问，并导出 `prices.csv`、`sec-context.json`、`config.toml`、完整报告与验收清单。

## 时点和输入大小

每次决策先以 `as_of - processing_delay_seconds` 作为信息截止点，再选择该时点已可得的最新正文版本。未来修订不能替换过去的正文；未来正文内容变化也不能改变较早决策的快照标识。行情修订与公告修订各自裁剪，可一起用于版本行情研究。

`availability_mode` 支持 `observed`（默认首次取得）、`declared`（有来源声明的公开时间）、`acceptance_proxy`（受理时间加假定公开延迟）。后两者的含义与独立事件研究一致。代理模式不向过去的模型输入暴露未来的首次取得时间。所有模式仍标记 `point_in_time_verified=false`：校验时间关系不等于证明供应方声明真实。

正文选择使用前缀，不能保证包含最重要的段落。报告标明截断与数量省略，每次决策所有股票的正文合计不超过 24000 字符。归档总计限制 64 MB；原文完整留存在证据中，不整篇发给模型。

策略可配置范围：回看 1..90 天，每股 1..10 个事件，每篇 200..8000 字符，处理延迟 1..86400 秒，公开延迟假设 60..604800 秒。事件可得时间、字段校验与历史映射由确定性代码处理，正文内的文字不能改变模型输出契约或风控限制。

## 覆盖与复现

- 每股单独记录历史映射是否存在、索引/映射是否覆盖整个回看区间、可见事件数、数量省略数和实际正文片段。
- 空事件列表只表示导入归档中没有当时可见的匹配记录；不能证明当时没有公告，索引覆盖也不能证明历史归档完整。
- 每个有效决策和模型失败记录都保留其公告上下文；报告包含实际行情、完整公告输入、配置和系统提示词。
- 研究登记时冻结公告与行情，之后从冻结输入执行。修改或删除原始文件不影响复现，篡改冻结文件会被拒绝。合成公告强制将研究标记为合成数据，不能得到通过历史验证的结论。
- 多候选比较要求使用同一公告输入，防止选定候选后悄悄换成另一套事件证据。

## 网页

在“SEC 历史事件研究”完成一次回放后，可下载“AI 回测公告输入”。该文件只含归档、映射和可得时间策略，不含事件收益结果。然后在上方主回测导入它，并提供匹配股票代码与日期的行情 CSV。

运行后可展开“最近一次决策可见的 SEC 公告”，检查正文、可得时间、截断和映射缺口；完整报告保存全部决策。合成公告不显示可点击的 SEC 文件链接，避免把虚构 accession 当作真实申报。

## 尚未完成

没有真实模型推理、真实 SEC 在线归档或历史可得性认证的验收证据；没有训练数据污染排除。事件输入不能替代财报结构化事实、行业知识或策略有效性检验。期权叠加回测仍是独立研究工具，尚未成为主模型可输出的交易资产。
