# SEC 历史事件研究验收

日期：2026-10-18。本批只运行离线研究、HTTP 模拟采集测试及临时本机网页服务；未运行真实模型、券商或持续任务。

- SEC 专项与原有 EDGAR 客户端测试 **33 项通过**，其中新模块 19 项。包括跨年季度、非法索引/来源路径、主文档选择、受理时区/DST、重复归档、正文修订留存、失败采集拒绝、首次取得和显式公开时间、事后修订不能提前可得、重叠/同日事件、休市日、窗口起点、分红/成本及 CLI/API 导出一致性。
- 包含期权、统一 AI、基础回测、运行账户、研究卡片、版本行情、队列及 SEC 的受影响回归 **169 项通过**。这一数量包含上述 33 项，不能相加。
- 随后的输入错误边界复核：期权与新 SEC 研究模块合计 **45 项通过**，无效日期/字段返回明确失败，不留下成功报告。这是上述回归的子集。
- 前端 **39 项通过**，生产构建通过；相关 Python 源码、测试和验收脚本 Ruff 通过。
- 实际离线输出位于 `runs/sec-events-validation-20261018/final/`：跨 2 个季度、9 份独立申报、去重 1 条、保留 1 个正文修订，形成 6 个事件组。网络尝试 0、模型调用 0、券商调用 0。
- 网页实际执行「加载跨季度合成样例 → 运行历史事件研究」，显示 1/3/5 日结果、样本数量、成本加倍和排除原因；逐项读取并比对下载报告，事件、汇总和全部输入与离线报告一致。证据为上一层 `ui-verification.json`。

样例全部为合成原文与价格，`research_conclusion="insufficient"`。实际 SEC 下载器使用 HTTP 模拟验证了季度遍历、身份校验、原文留存、重复下载和 503 部分失败；尚未用真实 User-Agent 完成在线采集联调。网页统计不是持仓受约束的投资组合收益，不能从技术验收推断投资效果。
