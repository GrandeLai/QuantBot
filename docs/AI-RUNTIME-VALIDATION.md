## 关键行为证据

- 美股和加密的次根开盘撮合、资金守恒、成本记账、精度、重启去重。
- 美股节假日和提前收盘，加密时区、连续性、未收盘数据、过期行情与历史修订拒绝。
- 模型请求中途暂停，迟到计划不会排队；进程中断后的恢复不会重复调用模型。
- 恢复事务再次中断时，运行状态与暂停状态一起回滚，下次恢复仍能识别未完成运行。
- 连续模型失败、日内亏损和账户回撤熔断；恢复保留历史权益高水位。
- 单笔取消、退出订单取消、模拟清仓、版本切换与恢复旧版本。
- 历史评估仅向模型传递对应时点的数据，实际撮合发生在后续 K 线。
- 受控 OpenAI 兼容协议经评估和持续运行调用链生成本地订单；实际收费模型请求数为 0。
- 工作进程互斥、独立心跳和退出清理；API 与 CLI 使用同一账本。
